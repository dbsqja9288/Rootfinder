### 얇은 페이지 문제 — 해결

해설이 없던 본관 페이지가 "정보 없음" 한 줄이었는데, **확인된 사실만 조합해** 실제 내용을 만들었습니다.

> 곡성 임씨는 임(任)씨가 본관으로 삼는 곡성 고을에서 갈라져 나온 갈래입니다. 곡성은 오늘날의 전라남도 곡성군입니다. 임씨는 전국에 약 172,000명이 있고, 이 사이트가 확인한 임씨 본관은 8개입니다. (…) 곡성을 본관으로 쓰는 다른 성씨도 1개 있습니다(곡성 신씨).

그리고 **"이 본관에 대해 아직 확인하지 못한 것"** 을 명시적으로 적습니다. 모르는 걸 아는 척하지 않는 게 이 사이트의 방침이고, 제보를 유도하는 장치이기도 합니다.

검색 결과 제목도 고쳤습니다. 시조 기록이 없는데 "시조와 유래"라고 걸어두면 검색으로 들어온 사람이 속았다고 느낍니다.

### 할 일 2 — 검색 등록 (10분)

> 💡 **도메인을 사실 거면 도메인 연결 후에 하세요.** 주소가 바뀌면 처음부터 다시 해야 합니다.

**구글**

1. <https://search.google.com/search-console> → 속성 추가 → **오른쪽 `URL 접두어`**
2. 주소 입력 → 소유확인에서 **`HTML 태그`** 선택
3. `content="여기값"` 의 **값만** 복사
4. Vercel → rootfinder → Settings → Environment Variables

| Key | Value |
| --- | --- |
| `NEXT_PUBLIC_GOOGLE_VERIFICATION` | 복사한 값 |

**네이버**

1. <https://searchadvisor.naver.com> → 웹마스터 도구 → 사이트 등록
2. **`HTML 태그`** 방식 → content 값만 복사

| Key | Value |
| --- | --- |
| `NEXT_PUBLIC_NAVER_VERIFICATION` | 복사한 값 |

3. 두 개를 **한 번에 넣고 Redeploy 한 번**만 하세요 (Deployments → 맨 위 ⋯ → Redeploy)
4. 배포 끝나면 각 콘솔에서 **확인** 클릭

**제출할 것**

| 어디 | 무엇 |
| --- | --- |
| 구글 Sitemaps | `sitemap.xml` |
| 네이버 요청→사이트맵 | `sitemap.xml` |
| 네이버 요청→RSS | `feed.xml` |
| 네이버 요청→웹페이지 수집 | 홈 주소 (수동 수집 요청) |

색인까지 구글은 며칠~2주, 네이버는 2주쯤 걸립니다.

### 할 일 3 — 애드센스 신청 (5분, 도메인 연결 후)

1. <https://adsense.google.com> → 시작하기 → **새 도메인** 입력
2. 애드센스가 주는 코드는 넣지 마시고, Vercel 환경변수에만:

| Key | Value | 어디서 |
| --- | --- | --- |
| `NEXT_PUBLIC_ADSENSE_CLIENT` | `ca-pub-...` | 애드센스 → 계정 → 계정 정보 |

3. Redeploy → 애드센스에서 **검토 요청** → 심사 2~4주

승인 후 광고 단위를 만들어 슬롯 번호를 받으면 `NEXT_PUBLIC_ADSENSE_SLOT` 에 넣습니다. 그때 본문에 광고가 붙습니다.

**얇은 페이지 걱정은 어제보다 줄었습니다.** 전부 실제 내용이 들어갔고 "확인하지 못한 것"을 명시해 성의를 보였습니다. 그래도 거절되면 해설 있는 255개만 남기고 재신청하면 됩니다. 재신청은 횟수 제한이 없습니다.
