# 검색 등록 + 수익화 안내

밤에 코드 쪽은 다 준비해뒀습니다. BJ님은 **복사·붙여넣기만** 하시면 됩니다.

각 단계는 서로 독립적입니다. 1·2단계(검색 등록)는 도메인 없이 **지금 바로** 가능하고,
3단계부터는 도메인을 사기로 결정하신 뒤에 하시면 됩니다.

---

## 제가 이미 해둔 것

| 항목 | 상태 |
| --- | --- |
| 개인정보처리방침 (`/legal/privacy`) | ✅ 작성 완료 |
| 이용약관 (`/legal/terms`) | ✅ 작성 완료 |
| 사이트 소개 (`/about`) | ✅ 작성 완료 |
| 푸터에 위 3개 + 문의 링크 | ✅ 연결 완료 |
| 구조화 데이터(JSON-LD) | ✅ 홈·본관 페이지에 삽입 |
| 사이트맵에 새 페이지 반영 | ✅ |
| 소유확인 메타태그 자리 | ✅ 환경변수만 넣으면 됨 |
| 광고 자리 | ✅ 만들어두고 꺼둠 (환경변수 넣으면 켜짐) |
| 사이트 주소 자동 인식 | ✅ 설정을 깜빡해도 진짜 주소가 나가게 고침 |

**광고는 지금 하나도 안 나옵니다.** 승인 후 값만 넣으면 그때 켜집니다. 코드를 다시 고칠 일은 없습니다.

## 1단계 — 구글 서치콘솔 (5분, 지금 가능)

### 1-1. 사이트 등록

1. <https://search.google.com/search-console> 접속
2. 왼쪽 위 속성 추가 → **`URL 접두어`** 쪽을 고릅니다
   - ⚠️ 왼쪽의 `도메인` 이 아니라 **오른쪽 `URL 접두어`** 입니다. 도메인 방식은 DNS 설정이 필요해서 지금은 못 씁니다.
3. `https://rootfinder-pi.vercel.app` 입력 → 계속

### 1-2. 소유확인

1. 소유권 확인 화면에서 **`HTML 태그`** 를 펼칩니다
2. 이런 게 나옵니다:
   ```html
   <meta name="google-site-verification" content="AbCdEf123456..." />
   ```
3. **`content=` 안의 값만** 복사합니다 (`AbCdEf123456...` 부분. 따옴표와 태그는 빼고)
4. Vercel → **rootfinder** → Settings → Environment Variables → Add

   | Key | Value |
   | --- | --- |
   | `NEXT_PUBLIC_GOOGLE_VERIFICATION` | 복사한 content 값 |

5. Deployments 탭 → 맨 위 배포 **⋯** → **Redeploy** (2~3분)
6. 배포가 끝나면 서치콘솔로 돌아와 **확인** 버튼

### 1-3. 사이트맵 제출

1. 왼쪽 메뉴 **Sitemaps**
2. `sitemap.xml` 입력 → 제출
3. 상태가 `성공` 이면 끝입니다

색인은 며칠~2주쯤 걸립니다. 조급해하지 않으셔도 됩니다.

---

## 2단계 — 네이버 서치어드바이저 (5분, 지금 가능)

한국 방문자에게는 네이버가 더 중요할 수 있습니다.

### 2-1. 사이트 등록

1. <https://searchadvisor.naver.com> 접속 → 네이버 로그인
2. **웹마스터 도구** → 사이트 등록
3. `https://rootfinder-pi.vercel.app` 입력

### 2-2. 소유확인

1. **`HTML 태그`** 방식을 고릅니다 (파일 업로드보다 간단합니다)
2. `<meta name="naver-site-verification" content="xxxxx">` 에서 **content 값만** 복사
3. Vercel 환경변수에 추가

   | Key | Value |
   | --- | --- |
   | `NEXT_PUBLIC_NAVER_VERIFICATION` | 복사한 content 값 |

4. **Redeploy** → 네이버에서 **소유확인** 클릭

> 💡 1단계와 2단계를 이어서 하시면 환경변수 두 개를 한 번에 넣고 **Redeploy를 한 번만** 하시면 됩니다.
> 그게 제일 빠릅니다.

### 2-3. 제출 3종

웹마스터 도구 안에서:

1. **요청 → 사이트맵 제출**: `sitemap.xml`
2. **검증 → robots.txt**: 수집이 막혀 있지 않은지 확인 (문제 없게 해뒀습니다)
3. **요청 → 웹페이지 수집**: 홈 주소를 넣어 수동으로 수집 요청

네이버는 검색 노출까지 보통 **2주 정도** 걸리고, 노출이 보장되지는 않습니다.

## 3단계 — 도메인 (애드센스의 전제 조건)

**`*.vercel.app` 으로는 애드센스 승인이 안 납니다.** 정책상 "사이트를 소유하거나 통제할 것"을
요구하는데 `vercel.app` 은 Vercel 소유이기 때문입니다. GitHub Pages, Netlify도 같습니다.

### 어디서 사나

**Cloudflare Registrar** 를 권합니다. 원가로 팔아서 갱신 때 가격이 뛰지 않습니다 (연 1~2만원).
가비아·후이즈도 되지만 첫 해만 싸고 갱신 때 비싸지는 경우가 많습니다.

### 이름 후보

`.com` 이 신뢰도와 검색 모두에 제일 낫습니다.

- `ppurichagi.com` — 사이트 이름 그대로
- `bongwan.com` / `bongwan.kr` — '본관'. 짧고 검색어와 맞음
- `myroots.kr` — 짧고 기억하기 쉬움
- `jokbo.kr` — '족보'

정하시면 구입 → Vercel 연결 → 기존 주소 리다이렉트까지 제가 단계별로 안내드리겠습니다.
구입 후에는 환경변수 하나만 바꾸면 사이트맵·구조화 데이터·공유 이미지가 전부 새 주소로 따라갑니다.

| Key | Value |
| --- | --- |
| `NEXT_PUBLIC_SITE_URL` | `https://새도메인.com` |

> ⚠️ 도메인을 바꾸면 **서치콘솔·서치어드바이저에 새 주소를 다시 등록**해야 합니다.
> 그래서 도메인을 살 생각이 있으시면, 1·2단계를 새 도메인으로 한 번에 하는 게 일이 줄어듭니다.
> 지금 당장 검색 유입이 급하지 않으시면 **도메인부터 정하고 시작하는 쪽**을 권합니다.

## 4단계 — 애드센스 신청

도메인 연결이 끝난 뒤에 하십시오.

1. <https://adsense.google.com> → 시작하기
2. 사이트 주소에 **새 도메인** 입력
3. 애드센스가 주는 코드는 **넣지 않으셔도 됩니다.** 대신 Vercel 환경변수에:

   | Key | Value | 어디서 |
   | --- | --- | --- |
   | `NEXT_PUBLIC_ADSENSE_CLIENT` | `ca-pub-...` | 애드센스 → 계정 → 계정 정보 |

   넣고 Redeploy 하면 애드센스가 요구하는 코드가 자동으로 `<head>` 에 들어갑니다.
4. 애드센스 화면에서 **검토 요청**
5. 심사 **2~4주**

승인이 난 뒤, 광고 단위를 만들고 슬롯 번호를 받아서 하나 더 넣으면 본문에 광고가 붙습니다.

| Key | Value |
| --- | --- |
| `NEXT_PUBLIC_ADSENSE_SLOT` | 광고 단위의 슬롯 번호 (숫자) |

### 거절되면

가장 흔한 사유가 **'가치가 낮은 콘텐츠'** 입니다. 지금 본관 페이지 706개 중 **485개가 이름과
지역만 있는 얇은 페이지**라 여기에 걸릴 가능성이 있습니다. 이 부분은 BJ님이 '보류'라고 하셔서
손대지 않았습니다. 거절되면 그때 다음 중 하나로 대응하면 됩니다.

- 얇은 페이지를 검색에서 제외(noindex)하고 해설이 있는 221개로 재신청 — 빠르고 안전
- 얇은 페이지에 지역 역사·인구·주변 본관 정보를 채워 넣기 — 검색 유입까지 늘어남

재신청은 횟수 제한이 없습니다. 거절이 불이익으로 남지 않습니다.

## 5단계 — 카카오 애드핏 (보조)

애드센스보다 승인 문턱이 낮아 먼저 붙여두기 좋습니다. 단가는 확실히 낮습니다.

1. <https://adfit.kakao.com> → 카카오 로그인 → 매체 등록
2. 웹사이트 주소 입력 → 광고 단위 생성
3. 받은 단위 ID를 Vercel 환경변수에:

   | Key | Value |
   | --- | --- |
   | `NEXT_PUBLIC_ADFIT_UNIT` | `DAN-...` |

애드센스와 애드핏이 둘 다 켜져 있으면 **단가가 높은 애드센스를 우선** 쓰도록 해뒀습니다.
애드핏만 켜면 애드핏이 나옵니다.

## 환경변수 총정리

Vercel → rootfinder → Settings → Environment Variables. 넣을 때마다 Redeploy가 필요합니다.

| Key | 언제 | 없으면 |
| --- | --- | --- |
| `MARKETING_KEY` | 대시보드 열 때 | 대시보드가 안 열림 |
| `THREADS_USER_ID` | 대시보드 지표용 | 스레드 숫자가 안 보임 |
| `THREADS_ACCESS_TOKEN` | 대시보드 지표용 | 스레드 숫자가 안 보임 |
| `NEXT_PUBLIC_GOOGLE_VERIFICATION` | 구글 등록 | 소유확인 실패 |
| `NEXT_PUBLIC_NAVER_VERIFICATION` | 네이버 등록 | 소유확인 실패 |
| `NEXT_PUBLIC_SITE_URL` | 도메인 구입 후 | Vercel 주소가 자동으로 쓰임 (지금은 이대로 정상) |
| `NEXT_PUBLIC_ADSENSE_CLIENT` | 애드센스 신청 시 | 광고 안 나옴 |
| `NEXT_PUBLIC_ADSENSE_SLOT` | 애드센스 승인 후 | 광고 안 나옴 |
| `NEXT_PUBLIC_ADFIT_UNIT` | 애드핏 승인 후 | 광고 안 나옴 |

## 수익 기대치 (정직하게)

한국 애드센스 페이지 RPM은 주제에 따라 크게 갈립니다. 금융·법률·의료가 1만~3만원으로 최상위인데,
**족보·성씨는 광고주가 붙을 상업적 의도가 약해 1,000~2,500원대**로 보는 게 맞습니다.

**하루 방문자 500명 · 세션당 2.5페이지 = 월 37,500 PV 기준**

| 시나리오 | 페이지 RPM | 월 수익 |
| --- | --- | --- |
| 보수적 | 1,000원 | 약 3만 7천원 |
| 중간 | 2,000원 | 약 7만 5천원 |
| 낙관적 | 3,000원 | 약 11만원 |

비용은 도메인 연 1~2만원이 전부입니다(Vercel·GitHub Actions는 계속 무료).
**하루 20~30명만 들어와도 도메인값은 회수**됩니다.

알아두실 것 두 가지:

- 애드센스는 **누적 $100(약 14만원)** 을 넘어야 송금됩니다. 위 기준이면 2~4개월에 한 번 입금됩니다.
- 진짜 변수는 단가가 아니라 **방문자 수**입니다. 지금 실제 트래픽은 Vercel → Analytics 에서 보세요.
  하루 500명은 아직 가정입니다.

## 추천 순서

1. **도메인을 살 생각이 있다면** → 도메인부터 정하고, 그 주소로 1·2단계를 한 번에 (일이 절반으로 줍니다)
2. **당분간 안 살 거라면** → 지금 주소로 1·2단계만 하고 검색 유입을 먼저 쌓기
3. 어느 쪽이든 애드핏은 도메인 없이도 시도해볼 수 있습니다
