# 게시 시계를 Vercel로 옮겼습니다

**BJ가 할 일: 아래 2·3단계, 합쳐서 5분.** 그 전까지는 글이 안 올라갑니다.

---

## 왜 옮겼나

깃허브 액션의 **예약 실행(cron)이 신뢰할 수 없다**는 게 드러났습니다.

| 날짜 | 무게시 시간 |
| --- | --- |
| 2026-08-26 | 12시간 |
| 2026-08-27 | **20시간** (분을 흩어도 안 살아남) |

그동안 확인한 것 — 워크플로 켜져 있음, 사용량 0분/2,000분, 설정 정상, 깃허브 상태 "Operational".
**우리 쪽에 고칠 게 없습니다.** 깃허브가 그냥 안 걸어줍니다. 무료 등급 예약 실행의 알려진 한계입니다.

그래서 **시계만** 옮겼습니다. 게시 코드는 한 줄도 안 바뀝니다.

```
전:  깃허브 예약 ────────────────────────> 깃허브 워크플로 ──> 스레드
                (여기가 안 걸림)

후:  Vercel Cron ──> /api/tick ──> 깃허브 워크플로 ──> 스레드
     (분 단위 정확)   (방아쇠만)     (그대로)
```

**왜 이게 되나** — 못 믿을 건 '예약'이지 '실행'이 아닙니다.
손으로 Run workflow 누른 건 지금까지 **한 번도 실패한 적이 없습니다.**
Vercel이 시간 맞춰 그 버튼을 대신 눌러주는 구조입니다.

스레드 토큰은 **깃허브 Secrets에 그대로** 둡니다. 건드리지 않습니다.

---

## 1단계 — 배포

`push.bat` 실행하면 아래가 올라갑니다.

| 파일 | 하는 일 |
| --- | --- |
| `src/app/api/tick/route.ts` | 깃허브 워크플로를 실행시키는 방아쇠 |
| `vercel.json` | 19개 시각표 (게시 18 + 성적수집 1) |

---

## 2단계 — 깃허브 토큰 만들기 (3분)

<https://github.com/settings/personal-access-tokens/new>

| 항목 | 값 |
| --- | --- |
| Token name | `rootfinder-cron` |
| Expiration | 원하는 만큼 (짧으면 갱신이 잦아집니다) |
| Repository access | **Only select repositories** → `Rootfinder` |
| Permissions → Repository permissions → **Actions** | **Read and write** |

**다른 권한은 아무것도 켜지 마세요.** 이 토큰이 할 수 있는 일은
"Rootfinder 저장소의 워크플로를 실행하는 것" 하나뿐이면 충분합니다.

**Generate token** 누르면 값이 한 번만 보입니다. 바로 다음 단계로.

---

## 3단계 — Vercel에 환경변수 2개 (2분)

Vercel → 프로젝트 → **Settings → Environment Variables**

| Key | Value |
| --- | --- |
| `GITHUB_DISPATCH_TOKEN` | 2단계에서 받은 토큰 |
| `CRON_SECRET` | 아무 긴 문자열 (예: `bburi-tick-9f3k2m8x`) |

`CRON_SECRET`은 Vercel이 이 주소를 두드릴 때 신분증처럼 붙여 보냅니다.
이게 없으면 아무나 주소를 두드려 스레드에 글을 쏟아낼 수 있습니다.

넣고 나서 **Redeploy** 해야 적용됩니다.

---

## 확인하는 법

Vercel → 프로젝트 → **Cron Jobs** 탭에 19개가 보이면 등록된 겁니다.
다음 예정 시각에 깃허브 Actions에 새 실행이 뜨면 성공입니다.

당장 확인하고 싶으면 Cron Jobs 탭에서 해당 줄의 **Run** 버튼을 눌러보세요.

## 알아둘 것

- **깃허브 예약도 아직 남겨뒀습니다.** 지금은 죽어 있지만 되살아날 수 있어서요.
  둘 다 걸리면 하루 36번이 되므로, 방아쇠 코드가 **"최근 20분 안에 이미 돌았나"를 먼저 확인**하고
  돌았으면 건너뜁니다. 중복 게시는 구조적으로 막혀 있습니다.
- Vercel 예약이 며칠 잘 도는 게 확인되면 깃허브 예약은 지우겠습니다.
- 게시 **시각은 그대로**입니다 (00:38, 01:11, 02:56 … 23:21).
- 토큰이 만료되면 게시가 멈춥니다. 만료일을 달력에 적어두세요.
