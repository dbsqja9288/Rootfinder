## 할 일 1 — X 자동 게시 켜기 (10분)

지금 코드는 **이미 X에 올릴 준비가 끝나 있습니다.** 열쇠 4개만 넣으면 바로 돕니다.
열쇠가 없는 동안에는 X 작업이 조용히 건너뛰어지고, 스레드는 지금처럼 계속 올라갑니다.

### 1-1. X 개발자 계정 만들기

1. <https://developer.x.com/en/portal/dashboard> 접속 (사이트 홍보에 쓸 X 계정으로 로그인)
2. **Sign up for Free Account** 클릭
3. 사용 목적을 영어로 250자 이상 적으라고 합니다. 아래를 그대로 붙여넣으세요.

```
I run a small hobby website that helps Korean users look up the origin of their
family name and clan seat. I want to use the X API only to publish scheduled
posts from my own account announcing the site and sharing fun result cards that
the site generates. I will not read, collect, analyze, or store any data about
other users. I will not build any product on top of X data. The posting happens
about six times a day through a simple GitHub Actions script that calls the
POST /2/tweets endpoint with text and one image. There is no user-facing
integration, no login with X, and no redistribution of X content.
```

4. 약관 동의 후 제출하면 바로 승인됩니다.

### 1-2. 앱 권한을 '쓰기'로 바꾸기

**이 단계를 빼먹으면 나중에 403 오류가 납니다. 꼭 하세요.**

1. 좌측 **Projects & Apps** → 자동으로 만들어진 앱 이름 클릭
2. **User authentication settings** → **Set up** (또는 Edit)
3. 이렇게 맞춥니다.
   - App permissions: **Read and write**
   - Type of App: **Web App, Automated App or Bot**
   - Callback URI: `https://rootfinder-pi.vercel.app/`
   - Website URL: `https://rootfinder-pi.vercel.app/`
4. **Save**

### 1-3. 열쇠 4개 뽑기

앱 화면의 **Keys and tokens** 탭으로 갑니다.

| 화면에 보이는 이름 | 우리가 쓸 이름 |
| --- | --- |
| API Key | `X_API_KEY` |
| API Key Secret | `X_API_SECRET` |
| Access Token | `X_ACCESS_TOKEN` |
| Access Token Secret | `X_ACCESS_SECRET` |

- API Key / Secret 은 **Regenerate** 를 누르면 화면에 나옵니다.
- Access Token / Secret 은 아래쪽 **Access Token and Secret** 의 **Generate** 를 누릅니다.
- ⚠️ **1-2(권한 바꾸기)를 한 뒤에 Access Token 을 만들어야 합니다.**
  순서가 반대면 읽기 전용 토큰이 나와서 게시가 안 됩니다.
  이미 만들었다면 **Regenerate** 로 다시 뽑으면 됩니다.
- 네 값 모두 메모장에 복사해 두세요. 창을 닫으면 다시 못 봅니다.

### 1-4. GitHub에 넣기

1. <https://github.com/dbsqja9288/Rootfinder/settings/secrets/actions>
2. **New repository secret** 을 눌러 **4번 반복**합니다.

| Name | Secret |
| --- | --- |
| `X_API_KEY` | 복사한 API Key |
| `X_API_SECRET` | 복사한 API Key Secret |
| `X_ACCESS_TOKEN` | 복사한 Access Token |
| `X_ACCESS_SECRET` | 복사한 Access Token Secret |

이름은 **대문자와 밑줄까지 정확히** 같아야 합니다.

### 1-5. 바로 테스트

1. <https://github.com/dbsqja9288/Rootfinder/actions>
2. 왼쪽 **소셜 자동 게시 (스레드 + X)** 클릭
3. 오른쪽 **Run workflow** → 초록 버튼 **Run workflow**
   - ⚠️ *Re-run all jobs* 가 아니라 **Run workflow** 입니다. Re-run 은 옛날 코드로 돕니다.
4. 1분 뒤 새로고침 → `X` 작업이 초록불이면 성공. X 계정에 글이 올라와 있습니다.

**X 무료 등급은 한 달 500개까지 쓸 수 있습니다.** 하루 6번이면 월 180개라 넉넉합니다.

## 할 일 2 — 마케팅 대시보드 열기 (3분)

스레드 성적, A/B 비교, 자동 게시 성공 여부를 **한 화면**에서 봅니다.
주소만 열면 그때그때 실시간으로 불러옵니다.

### 2-1. 비밀번호 정하기

1. <https://vercel.com/dashboard> → **rootfinder** 프로젝트 → **Settings** → **Environment Variables**
2. 아래 3개를 추가합니다. (Environment 는 셋 다 체크)

| Key | Value |
| --- | --- |
| `MARKETING_KEY` | 아무 문자열. 예: `bj-2026-roots` |
| `THREADS_USER_ID` | GitHub Secrets 에 넣어둔 값과 똑같이 |
| `THREADS_ACCESS_TOKEN` | GitHub Secrets 에 넣어둔 값과 똑같이 |

> 뒤의 두 개는 대시보드가 스레드 숫자를 읽어오는 데 씁니다.
> GitHub Secrets 는 값을 다시 볼 수 없으니, 처음 받았던 토큰 메모를 쓰시면 됩니다.
> 없으면 이 문서 맨 아래 '토큰 다시 받기'를 보세요.

3. **Save** → **Deployments** 탭 → 맨 위 배포의 **⋯** → **Redeploy**
   (환경변수는 다시 배포해야 적용됩니다.)

### 2-2. 즐겨찾기

```
https://rootfinder-pi.vercel.app/marketing?key=여기에-정한-비밀번호
```

이 주소를 즐겨찾기에 넣으세요. `key` 가 틀리면 아무것도 안 보입니다.
검색엔진에도 노출되지 않게 막아뒀습니다.

### 대시보드에서 보이는 것

- **팔로워 / 누적 조회 / 누적 좋아요** — 스레드 기준
- **A/B 소재 성적표** — 소재 A(MBTI)와 B(정보) 중 어느 쪽이 앞서는지 자동 판정
- **올라간 글** — 글별 조회·좋아요·댓글·리포스트, 바로가기 링크
- **자동 게시가 잘 돌고 있나** — 최근 실행 12건의 성공/실패
- **밖에서 봐야 하는 것** — Vercel Analytics, X Analytics, 서치콘솔 바로가기

> X와 사이트 트래픽은 무료 등급에서 조회 API를 안 열어줘서 링크로 뒀습니다.
> 억지로 붙이면 월 몇만 원이 나가는 유료 요금제가 필요합니다.

## 밤새 바뀐 것 (확인만 하시면 됩니다)

### 성씨 커버리지 — 75개 → **123개**, 본관 605개 → **706개**

말씀하신 **예(芮)씨, 마(馬)씨** 를 포함해 48개 성씨를 넣었습니다.

- 변(邊)·방(房)·방(龐)·정(程)·연(延)·표(表)·금(琴)·기(奇)·진(秦)·진(眞)·왕(王)·육(陸)·탁(卓)·제(諸)
- 어(魚)·국(鞠)·장(蔣)·용(龍)·은(殷)·태(太)·형(邢)·계(桂)·피(皮)·지(智)·전(錢)·음(陰)·온(溫)
- 호(扈)·좌(左)·초(楚)·팽(彭)·창(昌)·화(化)·종(宗)·옹(邕)·풍(馮)·해(海)·평(平)·환(桓)
- 두 글자 성씨: **남궁·황보·제갈·선우·독고·사공·서문**

작업 중에 버그도 하나 잡았습니다. 두 글자 성씨는 이름이 `함열 남` 처럼 잘려 나오고 있었고,
`문화 류씨` 처럼 표기가 두 개인 성씨는 본관이 통째로 이름에 남아 있었습니다. 둘 다 고쳤습니다.
새로 들어온 본관 전부에 "지금은 어디인가" 지역 정보도 붙였습니다.

### MBTI 결과 화면 — 공유 버튼 3개

`X` / `스레드` / `인스타` 버튼이 나란히 붙었습니다.

- **X, 스레드**: 누르면 결과 문구가 채워진 글쓰기 창이 열립니다.
- **인스타**: 인스타는 외부에서 글을 미리 채워주는 공식 통로가 없습니다. 그래서
  - **휴대폰** — 공유 시트가 떠서 인스타를 고르면 결과 이미지가 그대로 넘어갑니다 (스토리 공유에 제일 잘 맞습니다)
  - **PC** — 이미지를 내려받고 문구를 클립보드에 복사해 줍니다

## 토큰 다시 받기 (스레드 토큰을 잃어버렸을 때)

지금 쓰는 토큰이 살아 있다면 아래 주소로 60일 연장할 수 있습니다.

```
https://graph.threads.net/refresh_access_token?grant_type=th_refresh_token&access_token=지금쓰는토큰
```

완전히 잃어버렸다면 Meta 개발자 콘솔에서 새로 발급받아야 합니다.
말씀 주시면 그 절차도 단계별로 안내드리겠습니다.
